# Why IT Automation Platform

## 專案目的

IT Automation Platform 的目標不是建立 AI 平台，而是降低 IT 部門重複性工作的成本，
將固定 SOP 逐步轉換為可重複執行的自動化流程。

## 現況

目前許多工作都需要 MIS 人工處理，例如：

- VPN 申請
- 建立會議
- AD 帳號與群組
- 大檔案分享
- 其他固定流程

雖然流程不同，但都有共同特性：

- 有固定 SOP
- 有固定判斷規則
- 高度重複
- 容易因人工操作而產生錯誤

## 第一階段目標

建立一套標準化流程：

Request
→ Workflow
→ Notification

先聚焦於 IT 部門的需求，不追求一次涵蓋所有部門。

## AI 的角色

AI 不是平台核心，而是其中一種 Parser。

未來可由 Rule、API、Web Form 或 AI 解析需求，只要能產生標準化 Request 即可。

## 設計原則

- Automation First
- Rule First
- AI Optional
- 可逐步擴充 Workflow
